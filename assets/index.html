Kernel online · HTTP ready

Hello from Byte Ring OS.

This page is served directly from memory by an experimental Rust kernel. There is no disk, userspace web server, or operating system underneath it.

A small experiment with a different interface

The project explores submission and completion ring buffers carrying bounded bytecode programs. The goal is to make application interactions with the kernel more efficient, safe, reliable, and extensible. Those application queues are an architectural direction; this first HTTP endpoint runs inside the kernel.

From Ethernet to your browser

A modern virtio network device moves Ethernet frames through bounded DMA queues. A polled TCP/IP stack handles delivery, acknowledgements, retransmission, and connection shutdown. A small HTTP parser selects this immutable page and sends it with an exact content length, then closes the connection.

Hardware access uses a compile-time hardware abstraction layer, so portable logic can be tested on the host without privileged instructions. The kernel needs no heap allocation, scheduler, filesystem, or interrupts to serve this page. Fixed request and socket buffers make its initial limits explicit.
